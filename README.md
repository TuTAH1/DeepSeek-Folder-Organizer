# DeepSeek Folder Organizer

A Tampermonkey userscript that adds advanced folder organization capabilities to DeepSeek chat conversations. Organize your conversations into custom folders with icons and colors for better productivity and workflow management.

## Features

- **Custom Folders**: Create unlimited folders with custom names, icons, and colors
- **Visual Organization**: See folder tags directly next to conversation titles
- **Conversation Filtering**: Filter conversations by folder to focus on specific topics
- **Easy Management**: Add, rename, customize, and delete folders as needed
- **Persistent Storage**: All data stored locally in your browser
- **Search Functionality**: Search through conversations when managing folders
- **Intuitive Interface**: Clean, user-friendly interface that integrates seamlessly with DeepSeek

## Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension for your browser
2. Click on the [DeepSeek Folder Organizer script](https://raw.githubusercontent.com/Gzyms69/DeepSeek-Folder-Organizer/main/DeepSeek%20Folder%20Organizer-3.0.user.js) to install the userscript
3. Allow the installation in Tampermonkey
4. Navigate to [DeepSeek Chat](https://chat.deepseek.com/) to start using the organizer

## Usage

### Getting Started
1. Once installed, visit DeepSeek Chat
2. You'll see a "Folders" button appear in the sidebar
3. Click the "Folders" button to open the folder management panel

### Creating Folders
1. Click the "+" button in the folder panel header
2. Enter a name for your folder
3. Choose an icon and color for the folder
4. Click "Create"

### Organizing Conversations
1. Open the folder panel by clicking the "Folders" button
2. Right-click on any folder to open the context menu
3. Select "Manage Conversations"
4. Check the boxes next to conversations you want to add to the folder
5. Uncheck boxes to remove conversations from the folder
6. Click "Save Changes"

### Filtering Conversations
- Click on any folder name in the folder panel to filter conversations
- Click "All Conversations" to see all conversations again
- The folder panel can be toggled on/off using the "Folders" button

### Customizing Folders
- Right-click on any folder to access options:
  - Rename: Change the folder name
  - Customize: Change icon and color
  - Manage Conversations: Add/remove conversations from the folder
  - Delete: Remove the folder (conversations become unassigned)

## Privacy

All data is stored locally in your browser using Tampermonkey's storage API. No conversation data is sent to external servers.

## Compatibility

- Works with all modern browsers that support Tampermonkey (Chrome, Firefox, Edge, Safari)
- Compatible with the current DeepSeek Chat interface
- Automatically updates conversation lists when new conversations are created

## Troubleshooting

If you experience issues:
1. Refresh the DeepSeek Chat page
2. Check that Tampermonkey is enabled
3. Ensure the script is properly installed and enabled in Tampermonkey
4. Disable and re-enable the script if needed
